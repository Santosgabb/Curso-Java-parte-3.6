# Curso de Java: Orientação a Objetos - Parte 3.6 ☕

Módulo prático dedicado ao conceito de sobrecarga (*overloading*) de métodos e construtores em Java, permitindo que uma classe disponibilize múltiplas assinaturas para uma mesma operação.

---

## 📌 Conteúdos Abordados

* **Sobrecarga de Métodos (*Method Overload*)**:
  * Implementação de métodos com o mesmo identificador e diferentes listas de parâmetros (tipos e quantidades).
  * Flexibilidade na chamada de funções utilitárias e regras de negócio.
* **Sobrecarga de Construtores**: Criação de múltiplos caminhos de instanciação para uma entidade, de acordo com os dados disponíveis.
* **Reaproveitamento de Construtores com `this()`**: Encadeamento e boas práticas para evitar código duplicado.
